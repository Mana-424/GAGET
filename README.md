# GAGET

本作品は、漫画・アニメ『DEATH NOTE』に登場する、時計の内部に小さな収納スペースを備えた「隠し収納型時計」をモチーフに、その収納部分のみを拡大して模型化することを目的として製作している。

作中では、時計の内部に物を隠すことができる特殊な構造が描かれている。本作品では、その特徴的な収納機構に着目し、実際の時計では限られた大きさの内部構造を、拡大模型として再現することで、普段は見ることのできない内部の仕組みを分かりやすく表現することを目指した。

また、外観だけでなく、収納部分の構造や開閉の仕組みにも注目し、作品の再現性と模型としての機能性を両立させることを意識している。

この製作を通して、身近な時計に隠された特殊な機構を立体的に表現し、作品の世界観を感じられる模型を目指す。
